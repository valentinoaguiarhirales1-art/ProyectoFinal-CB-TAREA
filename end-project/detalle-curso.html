Curso de Desarrollo Web Frontend

Categoría: Programación web | Duración: 8 semanas

Descripción

Un curso para empezar desde cero en el desarrollo web. Verás cómo funciona una página web, cómo se organiza el contenido con etiquetas HTML y cómo dejar tus proyectos bien ordenados.

¿Qué vas a aprender?

  • Estructura de una página con HTML5.
  • Etiquetas semánticas, títulos y nociones de SEO.
  • Cómo organizar imágenes y archivos en carpetas.
  • Enlaces entre páginas con rutas relativas.

Requisitos

No hace falta saber programar. Solo necesitas un ordenador, un editor de código y ganas de aprender.
